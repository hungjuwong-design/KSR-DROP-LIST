# KhanSpeedrun Item Database (rebuild)

เว็บฐานข้อมูลไอเทม/มอนสเตอร์ดรอป เขียนใหม่ทั้งหมดจากข้อมูลเดิม (Static site, ไม่ต้องมี backend)

## สิ่งที่แก้/เพิ่มจากของเดิม
- **แยกตามอาชีพจริง** — อ่าน class จากตารางค่าสเตตัสของแต่ละไอเทมโดยตรง (Knight / Sorcerer / Assassin / Micko / Necromancer / Cleric) ไม่ต้อง guess จากชื่อ
- **แยกอาวุธตามหมวด** — Sword / Axe / Mace / Spear / Wand / Bow / Dagger ตามตารางอ้างอิงที่ให้มา ส่วนอาวุธ event/พิเศษที่ไม่อยู่ในตารางจะถูกจัดเข้ากลุ่ม "พิเศษ/กิจกรรม" อัตโนมัติ (เช็คได้ในหน้าเว็บ ถ้าอยากย้ายหมวดอันไหนบอกได้)
- **ลิงก์แยกต่อเซต** — ทุกไอเทมมี URL เฉพาะของตัวเอง เช่น `#/armor/Knight/helmets/<id>` หรือ `#/weapon/Sword/<id>` กด "คัดลอกลิงก์ไอเทมนี้" ในหน้ารายละเอียดเพื่อแชร์ตรงไปที่ไอเทมนั้นได้เลย ใช้ hash-routing เลยไม่มีปัญหา 404 ตอน refresh บน static host
- **แก้บั๊กข้อมูล** — ตัดรายการไอเทมว่าง/พัง 5 รายการที่หลุดมาจากระบบเดิม (ไม่มีชื่อ ไม่มีข้อมูลดรอป)
- **ค้นหาได้ทั้งชื่อไอเทมและชื่อมอนสเตอร์** จากช่องค้นหาด้านบน
- ตารางค่าดรอปยุบคอลัมน์ "อาชีพ" ที่เดิมพิมพ์ซ้ำทุกแถวออก (แสดงเป็น badge ที่หัวข้อแทน) และรวมค่าป้องกัน/โจมตี ต่ำสุด-สูงสุด ไว้ในคอลัมน์เดียวให้อ่านง่ายขึ้น
- รองรับมือถือ (responsive), โหลดรูปจากในโปรเจกต์เอง ไม่พึ่ง path เดิมที่อ้างอิงเครื่อง local ของคุณ Boss_ (ซึ่งใช้งานจริงไม่ได้)

## โครงสร้างโปรเจกต์
```
public/
  index.html        หน้าเว็บหลัก
  styles.css        ธีม
  app.js            ทุก logic (routing, render, search)
  data/full.json    ข้อมูลไอเทมทั้งหมด (parse มาจากไฟล์ html เดิมของคุณ)
  img/              รูปไอเทมทั้งหมด (นำมาจากไฟล์ที่อัปโหลด)
vercel.json
```
ไม่มี build step — เป็น static HTML/CSS/JS ล้วน ๆ เปิดไฟล์ `public/index.html` ตรง ๆ ในเบราว์เซอร์ก็ใช้งานได้ทันที (หรือรัน `npx serve public` เพื่อทดสอบ)

## วิธี deploy ขึ้น Vercel
ผมไม่มีสิทธิ์เข้าถึงบัญชี Vercel ของคุณ เลย deploy ให้ตรง ๆ ไม่ได้ครับ แต่ทำได้ 3 ทางง่าย ๆ (เลือกทางใดทางหนึ่ง):

**ทางที่เร็วที่สุด — ลาก-วาง**
1. ไปที่ https://vercel.com/new
2. ลากโฟลเดอร์ทั้งโปรเจกต์นี้ (หรือทั้งไฟล์ zip ที่แตกแล้ว) ไปวางในหน้าเว็บ
3. กด Deploy — เสร็จ ได้ลิงก์ทันที

**ทางที่ 2 — Vercel CLI**
```bash
npm i -g vercel
cd โฟลเดอร์โปรเจกต์นี้
vercel --prod
```

**ทางที่ 3 — ผ่าน GitHub (แนะนำถ้าจะแก้ไขต่อเรื่อย ๆ)**
1. สร้าง repo ใหม่บน GitHub แล้ว push โฟลเดอร์นี้ทั้งหมดขึ้นไป
2. เข้า https://vercel.com/new แล้วเลือก "Import Git Repository"
3. เลือก repo นี้ — Vercel จะ detect เป็น static site จาก `vercel.json` อัตโนมัติ กด Deploy

## แก้ไขข้อมูลภายหลัง
ข้อมูลทั้งหมดอยู่ใน `public/data/full.json` เป็นไฟล์เดียว แก้ตรงนี้แล้ว deploy ใหม่ได้เลย ไม่ต้องแตะโค้ด
