# KhanSpeedrun Item Database (rebuild)

เว็บฐานข้อมูลไอเทม/มอนสเตอร์ดรอป เขียนใหม่ทั้งหมดจากข้อมูลเดิม (Static site, ไม่ต้องมี backend)

## สิ่งที่แก้/เพิ่มจากของเดิม
- **แยกตามอาชีพจริง** — อ่าน class จากตารางค่าสเตตัสของแต่ละไอเทมโดยตรง (Knight / Sorcerer / Assassin / Micko / Necromancer / Cleric) ไม่ต้อง guess จากชื่อ
- **แยกอาวุธตามหมวด** — Sword / Axe / Mace / Spear / Wand / Bow / Dagger ตามตารางอ้างอิงที่ให้มา ส่วนอาวุธ event/พิเศษที่ไม่อยู่ในตารางจะถูกจัดเข้ากลุ่ม "พิเศษ/กิจกรรม" อัตโนมัติ (เช็คได้ในหน้าเว็บ ถ้าอยากย้ายหมวดอันไหนบอกได้)
- **ลิงก์แยกต่อเซต** — ทุกไอเทมมี URL เฉพาะของตัวเอง เช่น `#/armor/Knight/helmets/<id>` หรือ `#/weapon/Sword/<id>` กด "คัดลอกลิงก์ไอเทมนี้" ในหน้ารายละเอียดเพื่อแชร์ตรงไปที่ไอเทมนั้นได้เลย ใช้ hash-routing เลยไม่มีปัญหา 404 ตอน refresh บน static host
- **แก้บั๊กข้อมูล** — ตัดรายการไอเทมว่าง/พัง 5 รายการที่หลุดมาจากระบบเดิม (ไม่มีชื่อ ไม่มีข้อมูลดรอป)
- **ค้นหาได้ทั้งชื่อไอเทมและชื่อมอนสเตอร์** จากช่องค้นหาด้านบน
- ตารางค่าดรอปยุบคอลัมน์ "อาชีพ" ที่เดิมพิมพ์ซ้ำทุกแถวออก (แสดงเป็น badge ที่หัวข้อแทน) และรวมค่าป้องกัน/โจมตี ต่ำสุด-สูงสุด ไว้ในคอลัมน์เดียวให้อ่านง่ายขึ้น
- รองรับมือถือ (responsive), โหลดรูปจากในโปรเจกต์เอง ไม่พึ่ง path เดิมที่อ้างอิงเครื่อง local ของคุณ Boss_ (ซึ่งใช้งานจริงไม่ได้)

## โครงสร้างโปรเจกต์
```
public/
  index.html        หน้าเว็บหลัก
  styles.css        ธีม
  app.js            ทุก logic (routing, render, search)
  data/full.json    ข้อมูลไอเทมทั้งหมด (parse มาจากไฟล์ html เดิมของคุณ)
  img/              รูปไอเทมทั้งหมด (นำมาจากไฟล์ที่อัปโหลด)
vercel.json
```
ไม่มี build step — เป็น static HTML/CSS/JS ล้วน ๆ เปิดไฟล์ `public/index.html` ตรง ๆ ในเบราว์เซอร์ก็ใช้งานได้ทันที (หรือรัน `npx serve public` เพื่อทดสอบ)

## วิธี deploy ขึ้น Vercel
ผมไม่มีสิทธิ์เข้าถึงบัญชี Vercel ของคุณ เลย deploy ให้ตรง ๆ ไม่ได้ครับ แต่ทำได้ 3 ทางง่าย ๆ (เลือกทางใดทางหนึ่ง):

**ทางที่เร็วที่สุด — ลาก-วาง**
1. ไปที่ https://vercel.com/new
2. ลากโฟลเดอร์ทั้งโปรเจกต์นี้ (หรือทั้งไฟล์ zip ที่แตกแล้ว) ไปวางในหน้าเว็บ
3. กด Deploy — เสร็จ ได้ลิงก์ทันที

**ทางที่ 2 — Vercel CLI**
```bash
npm i -g vercel
cd โฟลเดอร์โปรเจกต์นี้
vercel --prod
```

**ทางที่ 3 — ผ่าน GitHub (แนะนำถ้าจะแก้ไขต่อเรื่อย ๆ)**
1. สร้าง repo ใหม่บน GitHub แล้ว push โฟลเดอร์นี้ทั้งหมดขึ้นไป
2. เข้า https://vercel.com/new แล้วเลือก "Import Git Repository"
3. เลือก repo นี้ — Vercel จะ detect เป็น static site จาก `vercel.json` อัตโนมัติ กด Deploy

## แก้ไขข้อมูลภายหลัง
ข้อมูลทั้งหมดอยู่ใน `public/data/full.json` เป็นไฟล์เดียว แก้ตรงนี้แล้ว deploy ใหม่ได้เลย ไม่ต้องแตะโค้ด

## อัปเดต: คลิกไอเทมในป๊อบอัพมอนสเตอร์ → แสดงแค่ popup ไอเทม ไม่พาไปหน้ารายการ

เดิมคลิกไอเทมดรอปในป๊อบอัพมอนสเตอร์จะ navigate (เปลี่ยน URL hash) พาไปหน้ารายการไอเทมของหมวดนั้นทั้งหน้า ตอนนี้แก้เป็น:

- คลิกไอเทม → เปิด popup แสดงแค่สถานะ/สเตตัสไอเทมนั้น (`KSR.app.openItemPopup(...)`) โดย **ไม่เปลี่ยน URL hash และไม่แตะ state เดิม** — หน้าแมพ/มอนสเตอร์ที่เปิดอยู่ข้างหลังยังอยู่เหมือนเดิมทุกอย่าง
- ปุ่ม **"← ย้อนกลับ"** ใน popup ไอเทมนี้ → ปิด popup ไอเทม แล้วเปิด popup มอนสเตอร์ตัวเดิมกลับมา (กลับไปหน้าเดิมที่เพิ่งดูอยู่)
- ปุ่ม **ปิด (X)** → ปิด popup ไอเทมไปเลย ไม่เปิดอะไรต่อ กลับไปเห็นหน้าแมพเดิมตรงๆ
- ปุ่ม "คัดลอกลิงก์ไอเทมนี้" ใน popup แบบนี้ยังคงคัดลอกลิงก์แบบเต็ม (ไปหน้ารายการ) ได้ปกติ สำหรับเอาไปแชร์
- การเปิดไอเทมแบบปกติ (คลิกจาก grid ในหมวดอาชีพ/อาวุธ/สกิล) ยังทำงานผ่าน URL hash เหมือนเดิมทุกอย่าง ไม่กระทบ



- โค้ดฝั่ง `public/app.js` แยกออกเป็นโมดูลย่อยใน `public/modules/` แล้ว:
  - `shared.js` — ค่าคงที่/state ร่วม/util ที่ทุกโมดูลใช้ (โหลดก่อนเสมอ)
  - `armor.js`, `weapon.js`, `skill.js` — โลจิกเฉพาะโหมดเดิม (ย้ายมาจาก app.js เดิม แก้ไขพฤติกรรมเดิมได้จากไฟล์เดียว ไม่ต้องไล่หาในไฟล์ยาว)
  - `mapmonster.js` — หน้าแผนที่/มอนสเตอร์ใหม่ทั้งหมด + popup มอนสเตอร์ที่ใช้ร่วมกับหน้าไอเทม
  - `app.js` ที่เหลือ (root) เป็นแค่ตัวเชื่อม routing + state กลาง ไม่มี business logic ของแต่ละโหมดแล้ว
  - **ไม่ใช้ ES modules** (import/export) เพื่อให้ยังเปิด `index.html` ตรง ๆ จากเครื่อง (double-click) ได้เหมือนเดิม และ deploy ขึ้น Vercel ได้แบบเดียวกับก่อนหน้านี้ — ทุกไฟล์เชื่อมกันผ่าน `window.KSR` namespace เดียว โหลดเรียงลำดับด้วย `<script>` tag ปกติ (ต้องโหลด `shared.js` ก่อนไฟล์อื่นเสมอ)

- ข้อมูลแผนที่/มอนสเตอร์อยู่ที่ `public/data/maps.json` — สร้างจาก MOBDatata.txt ครบทั้ง 14 แมพ
  - **ตอนนี้มีรูปครบทั้ง 14 แมพแล้ว** (Altai Gorge เพิ่มรูปแผนที่ล่าสุด — ยังไม่มีรูปมอนสเตอร์ในแมพนี้ 7 ตัว เลยยังโชว่กรอบตัวอักษรย่อแทน)
  - แก้ชื่อมอนสเตอร์ใน Lost Dungeon of Siberia (SIB2) จาก "BArmored Minotaur" (พิมพ์ผิดในต้นฉบับ) เป็น "**Armored Minotaur**" แล้ว — เช็คกับ `full.json` ยืนยันว่าไอเทมทุกชิ้นอ้างอิงชื่อ "Armored Minotaur" อยู่แล้ว การแก้ครั้งนี้เลยทำให้ลิงก์ไอเทมดรอปของมอนสเตอร์ตัวนี้ใช้งานได้ (เดิมเชื่อมไม่ติดเพราะชื่อไม่ตรงกัน)
  - จะเพิ่มรูปมอนสเตอร์ที่เหลือทีหลัง แค่แก้ `image` ใน `maps.json` ให้ชี้ไปที่ไฟล์รูปที่ใส่ไว้ใน `img/maps/<slug>/` ไม่ต้องแตะโค้ด
  - Object key ของแมพ (map slug) generate จากชื่อแมพอัตโนมัติ เช่น "Lost Dungeon of Siberia (SIB1)" → `lost-dungeon-of-siberia-sib1`

- **มอนสเตอร์คลิกได้ทุกที่ที่โผล่** — ทั้งใน grid มอนสเตอร์ของหน้าแผนที่ และ tag มอนสเตอร์ในหน้ารายละเอียดไอเทม (armor/weapon/skill) กดแล้วเปิด popup เดียวกัน: ชื่อ+รูปมอนสเตอร์, แผนที่ที่เจอ (กดไปแมพนั้นได้เลย), ไอเทมดรอปทั้งหมด (กดไปดูรายละเอียดไอเทมได้เลย) popup นี้ลอยซ้อนเหนือ popup ไอเทมเดิมได้โดยไม่ปิดของเดิม
